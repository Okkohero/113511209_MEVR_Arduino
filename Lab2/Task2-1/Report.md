### 1. 實驗目標(可參考課程投影片寫法)
- 結合可變電阻與 L293D。
- 透過讀取類比訊號（analogRead()），實現用旋鈕角度同時控制直流馬達的轉動方向與轉速。
- 達成中間位置停止、往左轉增加逆時針轉速、往右轉增加順時針轉速之控制邏輯。

### 2. 設備與元件
- Arduino Uno 開發板 x 1
- USB Type-B 傳輸線 x 1
- 個人電腦（已安裝 Arduino IDE）x 1
- L293D x 1
- DC 馬達 x 1
- 可變電阻 x 1
- 麵包板與連接線

### 3. 操作說明與成果
1. 電路接線：
    L293D 的8 腳跟16 腳接 Arduino 5V
    4、5、12、13 腳與 Arduino 的 GND 共地。
    PIN_1A 接數位接腳 7，PIN_2A 接數位接腳 8（控制正反轉）。
    EN1 接 PWM 接腳 11（控制致能與轉速）。
    可變電阻的訊號輸出端接至類比接腳 A0。
    馬達一端接在3腳，另一端接6腳。
2. 燒錄程式：使用 USB 線連接 Arduino Uno 至電腦，開啟 Task2-1.ino 程式並點擊「上傳」。
3. 實驗成果：
    測試停止區：將可變電阻旋鈕轉至正中間，觀察馬達停止轉動。
    測試逆時針旋轉：將旋鈕往左旋轉，馬達開始逆時針轉動，且轉速隨著旋轉幅度增加而變快。
    測試順時針旋轉：將旋鈕往右旋轉，馬達切換為順時針轉動，且同樣隨幅度增加而加速。
