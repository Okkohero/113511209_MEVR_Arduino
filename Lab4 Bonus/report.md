### 1. 實驗目標(可參考課程投影片寫法)
- 了解 PID（比例、積分、微分）控制器的基本原理，並應用於小球位置平衡控制系統。
- 學習使用 HC-SR04 超音波感測器測量小球與感測器之間的距離，取得小球的即時位置。
- 透過 SG90 伺服馬達調整軌道傾斜角度，使小球移動至指定目標位置。
- 調整 PID 控制參數 Kp、Ki、Kd，觀察不同參數對小球移動速度、震盪與穩定性的影響。

### 2. 設備與元件

- HC-SR04 超音波感測器 x 1
- SG90 伺服馬達 x 1
- 麵包板 x 1
- 小球軌道與支架
- 杜邦線數條
- USB 連接線 x 1

### 3. 操作說明與成果
1. 機構組裝：使用紙板製作小球移動軌道與支撐架，將 HC-SR04 超音波感測器固定於軌道一端，並使用線連接 SG90 伺服馬達與軌道底部，使伺服馬達能控制軌道的傾斜角度。

2. 感測器讀取與訊號處理：透過 HC-SR04 發送及接收超音波訊號，計算小球與感測器之間的距離。為減少測量雜訊造成的數值波動，可使用移動平均濾波，使位置資料更加穩定。

3. 伺服馬達角度設定：設定軌道水平時的伺服馬達基準角度為 90°，並將角度限制在約 75°～105°，避免軌道過度傾斜而使小球滾出軌道。實際角度依機構組裝情況調整。

4. PID 控制程式實作：設定小球的目標位置，計算目標位置與目前位置的誤差（Error），並利用 PID 控制器計算伺服馬達的角度修正量，使小球逐漸接近目標位置。

5. PID 參數調整：首先將 Ki 與 Kd 設為 0，逐步增加 Kp，觀察小球的移動與震盪情況；接著調整 Kd 以減少震盪，最後加入適當的 Ki，以降低穩態誤差並改善控制效果。

6. 實驗成果與觀察：預期系統能透過 HC-SR04 持續偵測小球位置，並根據位置誤差控制 SG90 伺服馬達改變軌道傾斜角度，讓小球朝指定位置移動。當 PID 參數調整適當時，應可減少小球在目標位置附近的來回震盪，使小球逐漸維持穩定。
